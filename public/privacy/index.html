プライバシーポリシー

「いたシャキ YouTube分析」におけるGoogleユーザーデータの取り扱いを説明します。

制定日：2026年9月4日

YouTube分析について 利用規約 配信スケジュール

1. 運営者と適用範囲

本ポリシーは、YouTubeチャンネル「いたシャキ！」の運営者が、自身のチャンネルを分析するために使用する「いたシャキ YouTube分析」に適用されます。

2. アクセスするGoogleユーザーデータ

本ツールは、YouTube Data APIおよびYouTube Analytics APIの読み取り専用権限を使用し、承認したチャンネルの次のデータにアクセスします。

  • チャンネル情報とライブ配信のメタデータ
  • 再生数、視聴時間、平均視聴時間などの集計値
  • 平均・最大同時接続数と配信中の同接推移
  • 登録者の増減と登録状態別の匿名集計

動画の作成、編集、削除、コメント投稿などの書き込み操作は行いません。

3. 利用目的

取得したデータは、配信実績の集計、開始時刻別の比較、視聴傾向の把握、今後の配信計画の改善にのみ使用します。広告配信、個人の識別、与信判断などには使用しません。

4. 保存方法と保持期間

分析データは、チャンネル所有者が管理する非公開のGoogleスプレッドシートに保存します。OAuthトークンはGoogle Apps Scriptのユーザープロパティで保護されます。データは分析に必要な期間保持し、スプレッドシートまたはApps Scriptプロジェクトの削除により消去されます。

5. 第三者への提供

取得したGoogleユーザーデータを販売、貸与、広告利用せず、法令上必要な場合を除き第三者に提供しません。Google APIを介して受信したデータの利用は、Google API Services User Data PolicyのLimited Use要件に従います。

6. 安全管理

認証情報をWebページやスプレッドシートのセルに公開せず、アクセス権限を読み取り専用に限定します。分析用スプレッドシートは非公開で管理します。

7. ユーザーの管理手段

チャンネル所有者は、Googleアカウントの接続アプリ管理から認証を解除できます。保存済みデータは、本人がGoogleスプレッドシートから確認・削除できます。

8. お問い合わせ

本ポリシーに関するお問い合わせは、Xの@xiv_itachikiまでお願いします。

9. 変更

利用するAPI、取得データ、または保存方法に重要な変更がある場合は、本ページを更新します。
